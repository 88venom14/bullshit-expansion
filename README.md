# Hysteria Config Bot

Браузерное расширение для быстрого доступа к Telegram-боту настройки Hysteria.

## Что делает расширение

1. **Открывает Telegram-бот** — при нажатии кнопки «Открыть бота» расширение переходит к боту [@hysteriyaconfig_bot](https://t.me/hysteriyaconfig_bot), который генерирует конфигурации Hysteria

2. **Считает клики** — сохраняет и отображает количество нажатий на кнопку открытия бота

3. **Считает посещения** — отслеживает, сколько раз открывалось popup-окно расширения

4. **Показывает уведомления** — при клике на кнопку появляется уведомление «✓ Переход выполнен»

## Как использовать

1. Нажмите на иконку расширения в браузере
2. Нажмите кнопку **«Открыть бота»**
3. Бот откроется в новой вкладке

Всё остальное (генерация конфигов, настройка сервера) делает Telegram-бот — расширение только открывает к нему доступ.
