# Hysteria Config Bot

Расширение для браузера, предоставляющее быстрый доступ к Telegram-боту для автоматической генерации и настройки конфигурации Hysteria.

![Version](https://img.shields.io/badge/version-1.0.0-blue)
![Manifest](https://img.shields.io/badge/manifest-v3-green)

## 📖 Описание

**Hysteria Config Bot** — это браузерное расширение, которое упрощает процесс настройки и конфигурации прокси-сервера Hysteria через Telegram-бот.

## ✨ Возможности

- 🚀 **Быстрый доступ** — запуск бота в один клик
- 🔒 **Безопасно** — использование официального Telegram-бота
- 📊 **Статистика** — отслеживание кликов и посещений
- 💎 **Удобный интерфейс** — современный и интуитивный дизайн

## 📦 Установка

1. Скачайте архив с расширением: [`hysteria-extension.zip`](hysteria-extension.zip)
2. Откройте браузер и перейдите на страницу `chrome://extensions/`
3. Включите **режим разработчика** (переключатель в правом верхнем углу)
4. Нажмите **«Загрузить распакованное расширение»**
5. Выберите папку с расширением

## 🎮 Использование

1. Нажмите на иконку расширения в панели браузера
2. Нажмите кнопку **«Открыть бота»** для перехода к Telegram-боту
3. Следуйте инструкциям бота для настройки конфигурации

- **HTML5/CSS3** — современный интерфейс

## 📊 Статистика

Расширение отслеживает:
- Количество кликов по кнопке открытия бота
- Количество открытий popup-окна

Данные сохраняются локально через `chrome.storage.local`.
